# HoPWaG India — Listening Companion (wiki)

Generated MkDocs Material site for the History of Philosophy (India) read-along notes.
Source of truth lives in `poopie/random/history of philosophy/` (local-only).

```
uv venv && uv pip install -r requirements.txt
.venv/bin/python build_docs.py
.venv/bin/mkdocs serve        # preview
.venv/bin/mkdocs gh-deploy --force
```
